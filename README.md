# FC Match Lab

FC 온라인 **감독모드 · 공식경기 · 친선경기** 기록을 모드별로 모아서, 내 경기와 내 선수의 성과를 분석하는 Windows 데스크톱 프로그램입니다.

[![최신 버전 내려받기](https://img.shields.io/github/v/release/QKRM/fc-match-lab-releases?label=%EB%82%B4%EB%A0%A4%EB%B0%9B%EA%B8%B0&style=for-the-badge&color=c9a24a)](https://github.com/QKRM/fc-match-lab-releases/releases/latest)

설치 파일(`FC-Match-Lab_x.y.z_x64-setup.exe`) 하나만 받아 실행하면 됩니다. Python, Node 같은 다른 프로그램은 설치하지 않아도 됩니다.

> **API 키가 필요합니다**
> FC Match Lab은 본인이 발급받은 **Nexon Open API 키**로 본인의 경기 기록을 직접 받아옵니다. 키는 [Nexon Open API](https://openapi.nexon.com/ko/game/fconline/)에서 무료로 발급받을 수 있습니다.

> **안내**
> 이 프로그램은 Nexon Open API로 받은 본인과 직접 조회한 상대의 경기 기록만 분석합니다. 게임 클라이언트에 개입하지 않습니다. Nexon이 만든 프로그램이 아니며, 사용에 따른 책임은 사용자에게 있습니다.

---

## 주요 기능

- **모드별 분석**: 감독모드, 공식경기, 친선경기(클래식 1on1)의 전적과 지표를 섞지 않고 따로 봅니다
- **경기 상세**: 스코어, 팀 비교(점유율·슈팅·패스·태클·차단), 득점 타임라인, 양 팀 선수 기록, 경기 메모
- **슈팅 지도**: 내 슈팅과 상대 슈팅(실점 위치)을 밀도 또는 개별 슛으로 표시하고, 슛 종류·결과·선수별로 거릅니다
- **경기 분석**: 유효슈팅 비율, 득점 전환율, 패스·스루패스·태클 성공률, 시간대·요일별 전적, 15분 단위 득실점 시간, 슛 종류별 성과
- **선수 분석**: 카드 · 강화 · 포지션별 출전, 골, 도움, 슛, 패스 성공률, 평균 평점. 선수를 누르면 그 선수가 뛴 경기를 봅니다
- **감독모드 FC**: 등급별 승리 × 보상 규칙으로 예상 FC를 날짜·시간대·시즌·등급별로 계산합니다. 보상 규칙은 직접 바꿀 수 있습니다
- **기간 · 결과 필터**: 오늘, 최근 7·14일, 직접 지정 / 승·무·패 / 몰수 포함 여부
- **여러 계정**: 닉네임이 다른 계정을 등록하고 전환합니다
- **자동 업데이트**: 새 버전이 나오면 알려주고, 버튼 한 번으로 설치 후 다시 시작합니다

## 설치

1. 위 **내려받기** 버튼에서 최신 `FC-Match-Lab_x.y.z_x64-setup.exe`를 받습니다
2. 실행하면 현재 사용자 계정에 설치됩니다 (관리자 권한 필요 없음)
3. WebView2가 없는 PC는 설치 중에 자동으로 준비합니다

> 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다. 코드 서명 인증서가 없는 개인 개발 프로그램이라 그렇습니다. **추가 정보 → 실행**을 누르세요.

## 처음 사용하기

### 1. API 키 발급과 등록 (처음 한 번, 약 5분)

키는 무료이며 넥슨 계정만 있으면 됩니다. 계정이 없으면 [nexon.com](https://www.nexon.com)에서 먼저 가입하세요.

**① 애플리케이션 등록 페이지 열기**

[애플리케이션 등록 페이지](https://openapi.nexon.com/ko/my-application/create-app/)로 가서 넥슨 계정으로 로그인합니다.

**② 애플리케이션 정보 입력**

등록 화면의 항목을 아래처럼 채웁니다. 그대로 복사해 붙여 넣어도 됩니다.

| 항목 | 입력할 내용 |
|---|---|
| 게임 | FC온라인 |
| 앱 이름 | `FC Match Lab` |
| 앱 설명 | `FC온라인 내 경기 기록을 받아 PC에서 분석하는 개인용 프로그램입니다.` |
| 서비스 URL | `https://github.com/QKRM/fc-match-lab-releases` |

입력을 마치면 화면 아래의 **등록** 버튼을 누릅니다.

> 처음 등록하면 **개발 단계** 키가 나옵니다. 혼자 쓰기에는 개발 단계로도 충분하지만, 하루 1,000건 한도 때문에 감독모드를 많이 하는 계정은 첫 동기화가 이틀에 걸쳐 끝날 수 있습니다. 더 빠르게 쓰고 싶으면 같은 화면에서 **서비스 단계**로 신청하세요. 서비스 단계는 서비스 정보를 정확히 적어야 승인됩니다.

**③ 등록한 애플리케이션 열기**

등록이 끝나면 내 애플리케이션 목록으로 이동합니다. 방금 만든 **FC Match Lab**을 눌러 상세 화면을 엽니다.

**④ API 키 복사**

상세 화면에서 API 키 옆의 **복사** 버튼을 누릅니다. 키는 `test_` 또는 `live_`로 시작하는 긴 문자열이며, 따로 확인할 필요 없이 바로 다음 단계로 가면 됩니다.

**⑤ FC Match Lab에 붙여 넣기**

1. FC Match Lab을 실행합니다
2. 첫 화면의 **Nexon API 키** 칸에 붙여 넣고 (`Ctrl+V`) **저장**을 누릅니다
3. 다음 화면에서 구단주 닉네임을 등록하면 키가 정상인지 함께 확인됩니다

나중에 키를 바꾸려면 **설정 → API 키 → 새 키로 교체**에 새 키를 넣으세요.

> **키 관리 주의**
> - 키는 **Windows 자격 증명 관리자**에만 저장되고, 경기 DB나 백업 파일에는 들어가지 않습니다
> - 키를 디스코드·카페·방송 화면 등에 노출하지 마세요. 다른 사람이 내 호출 한도를 써 버릴 수 있습니다
> - 노출됐다면 Nexon Open API의 내 애플리케이션에서 **키 재발급**(또는 삭제 후 다시 등록)을 하고, 새 키로 교체하세요
> - 키 하나로 내 계정뿐 아니라 친구 닉네임도 등록할 수 있습니다. 대신 호출 한도를 함께 씁니다

| 키 종류 | 호출 한도 | 프로그램 동작 |
|---|---|---|
| 개발 단계 (`test_…`) | 초당 5건, 하루 1,000건 | 초당 4건으로 천천히 받습니다. 경기가 많은 계정은 첫 동기화가 하루에 끝나지 않을 수 있습니다 |
| 서비스 단계 (`live_…`) | 초당 500건, 하루 2,000만 건 | 초당 40건, 8건씩 동시에 받습니다 |

하루 한도를 다 쓰면 동기화가 멈추고 안내 문구가 나옵니다. 남은 경기는 다음 동기화 때 이어서 받습니다.

### 2. 구단주 등록과 첫 동기화

1. 구단주 닉네임을 입력하고 수집할 모드를 고릅니다
2. 오른쪽 위 **동기화**를 누르면 최근 경기부터 받아옵니다
3. 상단 상태 표시에서 저장 건수, 대기·실패 건수, 마지막 성공 시각을 확인합니다

## 알아둘 점

- **Nexon API는 최근 약 30일 경기만 제공합니다.** 그보다 오래된 경기는 받을 수 없습니다
- 한 번 받은 경기는 PC에 저장되므로, **30일 안에 한 번 이상 동기화**하면 기록이 빠짐없이 쌓입니다
- 데이터는 매시 정각에 두 시간 전 경기까지 반영됩니다. 방금 끝난 경기는 바로 보이지 않습니다
- 상대가 통계가 만들어지기 전에 나가면 상대 쪽 기록이 비어 있을 수 있습니다. 화면에 "상대 기록 없음"으로 표시합니다
- 몰수 경기는 전적에는 들어가지만, 득실점·슈팅 같은 성과 집계에서는 기본으로 뺍니다 (필터로 포함 가능)
- 출전 시간 정보가 없어 90분당 지표는 제공하지 않습니다. 교체 대기(미출전) 선수는 선수 집계에서 뺍니다
- **감독모드 FC는 예상치입니다.** 기본 규칙은 챔피언스 승 +15, 슈퍼챔피언스 승 +20(몰수승 포함)이며, 실제 잔액과 다를 수 있습니다. 게임 정책이 바뀌면 FC 화면의 보상 규칙에서 수정하세요

## 자주 묻는 질문

**Q. 왜 API 키를 직접 발급받아야 하나요?**
중계 서버 없이 내 PC가 Nexon에서 바로 받아오기 때문입니다. 내 한도만 쓰므로 다른 사용자의 영향을 받지 않고, 내 경기 기록이 다른 서버를 거치지 않습니다.

**Q. 업데이트하면 기록이 사라지나요?**
아니요. 프로그램 파일만 바뀌고, 계정·API 키·저장된 경기는 그대로 남습니다. 업데이트 파일은 서명을 확인한 뒤에만 설치됩니다.

**Q. 키를 바꾸고 싶어요.**
설정 → API 키 → **새 키로 교체**에 새 키를 넣으면 됩니다.

## 데이터 저장 위치

| 내용 | 위치 |
|---|---|
| 경기 기록 DB | `%APPDATA%\com.fcmatchlab.app\fcml.sqlite` |
| API 키 | Windows 자격 증명 관리자 (`FC Match Lab`) |
| 프로그램 | `%LOCALAPPDATA%\FC Match Lab\` |

다른 사람에게 DB 파일을 보내면 내 경기 기록과 상대 닉네임이 함께 전달됩니다.
